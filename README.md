# Ek Bagiya Maa Ke Naam Dashboard

Static GitHub Pages-ready dashboard for Ek Bagiya Maa Ke Naam - Satna / Maihar.

## How to publish on GitHub Pages

1. Create a new GitHub repository, for example `ek-bagiya-dashboard`.
2. Upload all files from this folder to the repository root:
   - `index.html`
   - `data.js`
   - `upyantri_rank_full_table.csv`
   - `work_details.csv`
   - `.nojekyll`
3. Open repository **Settings → Pages**.
4. Set **Source** to `Deploy from a branch`.
5. Select branch `main` and folder `/root`.
6. Save.

Your site will be available at:

`https://YOUR-GITHUB-USERNAME.github.io/ek-bagiya-dashboard/`

## Update data later

Replace the files in this repository with the new generated dashboard files and commit the changes.
